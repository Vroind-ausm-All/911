# 911.exe — Maximalismus-Memeseite

Eine Single-Page-Memeseite rund um die Zahl **911**: Porsche 911, Notruf, Aviation-Memes.
Kein Build, keine Dependencies — `index.html` im Browser öffnen.

Stil: Maximalismus. Neon-Gradients, Marquees, rotierende Karten, fliegendes Emoji-Konfetti,
Comic-Sans-Captions, ein Meme-Generator und eine Tier List.

## Features
- Blinkende Alarm-Leiste + 4 Laufschriften
- 4 Meme-Grids (Auto, Flugzeuge, Notruf, Tier List) mit Shuffle
- „Notruf absetzen"-Generator und ein Hue-Rotate-Chaos-Button
- Fakten-Kacheln und der 911-Übersetzer
- `prefers-reduced-motion` wird respektiert

## Hinweis
Satire/Fanprojekt, nicht mit Porsche AG, Fluglinien oder Notrufzentralen verbunden.
Bewusst **ohne** Bezug auf die Anschläge vom 11. September.
Echte Notfälle: 112 (EU) / 911 (US).

## `cybersecurity/` — KI baut. Du haftest.

Zweite, eigenständige Seite im Repo: ein Cybersecurity-Handbuch für Webseiten, die
eine KI geschrieben hat. Swiss Design (12-Spalten-Raster, Helvetica, Rot/Schwarz/Papier)
mit Parallax-Überschriften, Hover-Effekten und Hell-/Dunkel-Modus.
Kein Build, keine Dependencies — `cybersecurity/index.html` im Browser öffnen.

### Inhalt
- **01 Warum** — warum „läuft" nicht „hält stand" heißt
- **02 Ursachen** — vier strukturelle Gründe, warum Modelle dieselben Fehler wiederholen
- **03 Handbuch** — 18 Fehlerklassen (F—01 bis F—18), filterbar nach Zone
  (Eingang · Grenze · Ausgang · Lieferkette · Betrieb) und Schwere, mit Volltextsuche.
  Jeder Eintrag: Symptom, Warum die KI das tut, Was es kostet, falscher Code,
  richtiger Code, Sofort-Check, Prompt-Fix zum Kopieren
- **04 Check** — 12-Punkte-Deploy-Checkliste, Stand bleibt lokal im `localStorage`
- **05 Prompts** — vier Prompt-Bausteine, die Sicherheit von vornherein mitbestellen

### Bedienung
`G` Raster ein/aus · `/` Suche fokussieren · `T` Hell/Dunkel · `#f-07` verlinkt direkt
auf einen Handbuch-Eintrag. `prefers-reduced-motion` und `prefers-color-scheme` werden
respektiert.

Defensives Lehrmaterial: erkennen, prüfen, reparieren. Die genannten Tests gehören auf
eigene Systeme.
