# 911.exe — Maximalismus-Memeseite

Eine Single-Page-Memeseite rund um die Zahl **911**: Porsche 911, Notruf, Aviation-Memes.
Kein Build, keine Dependencies — `index.html` im Browser öffnen.

Stil: Maximalismus. Neon-Gradients, Marquees, rotierende Karten, fliegendes Emoji-Konfetti,
Comic-Sans-Captions, ein Meme-Generator und eine Tier List.

## Features
- Blinkende Alarm-Leiste + 4 Laufschriften
- 4 Meme-Grids (Auto, Flugzeuge, Notruf, Tier List) mit Shuffle
- „Notruf absetzen"-Generator und ein Hue-Rotate-Chaos-Button
- Fakten-Kacheln und der 911-Übersetzer
- `prefers-reduced-motion` wird respektiert

## Hinweis
Satire/Fanprojekt, nicht mit Porsche AG, Fluglinien oder Notrufzentralen verbunden.
Bewusst **ohne** Bezug auf die Anschläge vom 11. September.
Echte Notfälle: 112 (EU) / 911 (US).
